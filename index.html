01

Graph fundamentals

A graph G = (V, E) consists of vertices V and edges E connecting pairs of vertices. In this lab, graphs are undirected (an edge works in either direction) and weighted (each edge has a cost).

G = (V, E, w)  ·  w : E → ℝ

A road network is a useful model: junctions are vertices, roads are edges, and their installation cost or distance is the weight.

02

Spanning trees & minimum cost

A spanning tree reaches every vertex in a connected graph without cycles. Every spanning tree on V vertices has exactly V − 1 edges. A minimum spanning tree (MST) is the spanning tree whose total weight is smallest.

w(T) = Σe ∈ T w(e)  →  min
◎

Sample graph: AB=1, BC=2, AC=3, CD=4, BD=5. The MST chooses AB, BC, CD for a total weight of 7.

Negative edge weights are allowed. If equal weights exist, multiple different MSTs can share the same minimum total.

03

The greedy choice & cut property

A greedy algorithm commits to a locally cheapest safe choice. The cut property explains why it works: for any cut dividing vertices into two sets, a minimum-weight edge crossing that cut is safe to include in some MST.

lightest edge crossing a cut  ∈  some MST

Prim grows one connected component and repeatedly crosses its boundary. Kruskal grows a forest and joins separate components.

04

Kruskal: join components

Sort edges in nondecreasing weight order. For each edge, use Find to check whether its endpoints already share a component. If not, accept it and Union the two components. Stop at V − 1 accepted edges.

  1. Sort E edges by weight.
  2. Start with each vertex in its own set.
  3. Accept an edge only when its endpoints are in different sets.
  4. Report a forest if the graph is disconnected.
O(E log E)   sorting dominates
05

Prim: grow one component

Choose a start vertex. Maintain each unvisited vertex’s cheapest known connection (key) to the tree. Repeatedly extract the minimum-key vertex from a binary min-heap and relax its adjacent edges.

key[v] = min weight of an edge from v into the tree

With an adjacency list and binary min-heap, the implementation here runs in O((V + E) log V). If a vertex remains unreachable, Prim continues with a new component and reports the graph as disconnected.

06

Union-Find (disjoint sets)

Union-Find tracks connected components using parent forests. Find(x) locates the representative; Union(a,b) joins two sets. The simulator compares four C implementations.

NaiveAttach one root to another.
Union by rankAttach the shallower tree below the taller.
Path compressionFlatten the path during Find.
Rank + compressionBoth optimizations; amortized O(α(V)).

Rank is an upper bound on tree height. Path compression rewrites each visited parent to the root, making future finds cheaper.

07

Complexity at a glance

Theory predicts asymptotic growth; the analysis dashboard separately measures actual C/WASM execution on generated graphs. Measurements depend on your browser and hardware.

Infrastructure Network Design Using Minimum Spanning Tree Algorithms

An interactive educational application for exploring Prim’s and Kruskal’s greedy algorithms. Every algorithm, disjoint-set operation, and benchmark runs in C compiled to WebAssembly; JavaScript handles graph editing and visualization.
